What this mailbox is for

			

				This is a disposable address for short-term use: sign-ups, verification codes, downloads, or any situation where you do not want to expose your real email. Messages are only kept for the active lifetime of the mailbox.
			

			
How do I use my last mailbox address again?

			

				When the countdown reaches zero, incoming mail stops until you reactivate the same mailbox. Reactivating runs a fresh proof-of-work step and extends the validity so you can keep using the same address and inbox.
			

			

				After you create a mailbox, this page’s URL includes a token in the address bar. Bookmark or save that link so you can open it later and use Reactivate Mailbox to restore access without creating a new address.
